# Python Module 00
## Milestone 2 / 42 Porto

### Description
Module 00 contains basic exercises to understand Python syntax.

### Instructions
To copy the main file into the folders for testing, you can use (inside the 'ex' folder):
```bash
cp ../main.py .
```
To execute:
```bash
python3 main.py
```
And to check the flake8:
```bash
python3 -m flake8
```
